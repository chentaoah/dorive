### 定义实体

自定义工厂，支持根据字段值，创建不同的实体。

定义外部订单，继承订单，并重写获取商品编码的方法：

```java
/**
 * 外部订单
 */
@Entity
public class ExternalOrder extends Order {
    /**
     * 获取商品编码
     */
    @Override
    public String getProductCode() {
        return "I am ExternalOrder!";
    }
}
```

### 定义工厂

自定义工厂，继承默认工厂，并重写适配方法。

```java
@Component
public class OrderFactory extends DefaultEntityFactory {
    @Override
    protected void initEntityAdapter() {
        Map<Object, Class<?>> valueEntityTypeMap = new ConcurrentHashMap<>();
        valueEntityTypeMap.put("External", ExternalOrder.class);
        setEntityAdapter(new AdaptiveEntityAdapter(getEntityElement(), Order::getType, valueEntityTypeMap));
    }
}
```

### 仓储指定工厂

```java
@Repository(
        dataSource = OrderMapper.class,
        factory = OrderFactory.class,
        queries = OrderQuery.class
)
public class OrderRepository extends MybatisPlusRepository<Order, Integer> {
}
```

### 验证

```java
LambdaExample<Order> lambdaExample = new LambdaExample<>();
lambdaExample.eq(Order::getType, "External");
List<Order> orders = repository.selectByExample(Options.ALL, lambdaExample);
Order order = orders.get(0);
System.out.println(order.getProductCode());
```

控制台打印：I am ExternalOrder!
