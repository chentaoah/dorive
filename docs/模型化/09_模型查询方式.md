### 倒推查询

使用场景：

- 数据不在同一个数据库

#### 指定查询方式

```java
DefaultContext context = new DefaultContext(Context.ALL);
// 指定为倒推查询
context.setOption(QueryMethod.class, QueryMethod.STEPWISE);
OrderQuery orderQuery = new OrderQuery();
orderQuery.setProductCode("IPHONE16");
List<Order> orders = repository.selectByQuery(context, orderQuery);
```

#### 实际过程

第一步：

```sql
select order_id from order_detail where product_code = 'IPHONE16'
```

第二步：

```sql
select id, type, create_time from order where id in (1, 2, 3)
```

第三步：

```sql
select id, orderId, product_code, amount from order_detail where orderId in (1, 2, 3)
```



### 联表查询

```java
DefaultContext context = new DefaultContext(Context.ALL);
OrderQuery orderQuery = new OrderQuery();
orderQuery.setType("External");
orderQuery.setProductCode("IPHONE16");
List<Order> orders = repository.selectByQuery(context, orderQuery);
```

#### 实际过程

第一步：

```sql
select 
    distinct t1.id 
from 
    order t1
left join 
    order_detail t2 on t2.order_id = t1.id
where
    t1.type = 'External'
    and t2.product_code = 'IPHONE16'
```

第二步：

```sql
select id, type, create_time from order where id in (1, 2, 3)
```

第三步：

```sql
select id, orderId, product_code, amount from order_detail where orderId in (1, 2, 3)
```



### 自定义查询

当自动生成SQL的无法满足需求时，框架还支持自定义查询语句。

#### 新增查询对象

配置映射方法名（method），如下：

```java
@Data
@Query(method = "select1")
public class OrderQuery1 {
    // 主键
    private Integer id;
    // 订单类型
    private String type;
    // 下单时间
    private Date createTime;
    // 商品编码
    @QueryField("OrderDetail")
    private String productCode;
    // 排序字段
    private String sortBy;
    // 排序方式
    private String order;
    // 页码
    private Integer page;
    // 条目数
    private Integer limit;
}
```

#### 仓储绑定查询对象

添加查询对象OrderQuery1：

```java
@Repository(
        dataSource = BizOrderMapper.class,
        queries = {OrderQuery.class, OrderQuery1.class}
)
public class OrderRepository extends MybatisPlusRepository<Order, Integer> {
}
```

#### 修改Mapper

添加select1方法：

框架会通过反射，调用该方法。该方法可以定义context、query、orderBy、page四个入参。

当然，也可以直接使用Mybatis-Plus的Page，但必须满足Mybatis-Plus的要求（首个入参）。

```java
import com.baomidou.mybatisplus.extension.plugins.pagination.Page;
import com.gitee.dorive.core.entity.executor.OrderBy;

/**
 * 订单
 * Generated by MyBatis Generator on 2025-01-06
 */
@Mapper
public interface BizOrderMapper extends BaseMapper<BizOrder> {

    List<Integer> select1(Page<BizOrder> page, @Param("context") Map<String, Object> context, @Param("query") Object query, @Param("orderBy") OrderBy orderBy);

}
```

#### 修改Mapper.xml

添加select1方法：

开发者仅需根据自身需求，查询出主表id即可。

```xml
<select id="select1" resultType="java.lang.Integer">
    select
    distinct t1.id
    from biz_order t1
    left join biz_order_detail t2 on t2.order_id = t1.id
    where 1 = 1
    <if test="query.type != null">
        and t1.type = #{query.type}
    </if>
    <if test="query.productCode != null">
        and t2.product_code = #{query.productCode}
    </if>
    <if test="orderBy != null">
        ${orderBy}
    </if>
</select>
```

#### 测试

```java
Context context = new DefaultContext(Context.ALL);
OrderQuery1 orderQuery = new OrderQuery1();
orderQuery.setType("External");
orderQuery.setProductCode("IPHONE16");
orderQuery.setSortBy("id");
orderQuery.setOrder("desc");
orderQuery.setPage(1);
orderQuery.setLimit(10);
List<Order> orders = orderRepository.selectByQuery(context, orderQuery);
```

实际执行SQL：

```sql
select distinct t1.id
from biz_order t1
         left join biz_order_detail t2 on t2.order_id = t1.id
where 1 = 1
  and t1.type = 'External'
  and t2.product_code = 'IPHONE16'
ORDER BY id DESC
LIMIT 10
```
