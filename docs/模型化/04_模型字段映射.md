### 字段名映射

当实体字段（驼峰）与表字段（下划线）不一致时，需配置映射关系。

```java
/**
 * 订单详情
 */
@Data
@Entity
public class OrderDetail {
    // 主键
    private Integer id;
    // 订单ID
    private Integer orderId;
    // 商品编码
    @Alias("order_product_code")
    private String productCode;
    // 商品金额
    private BigDecimal amount;
}
```

### 字段值映射

```java
/**
 * 订单详情
 */
@Data
@Entity
public class OrderDetail {
    // 主键
    private Integer id;
    // 订单ID
    private Integer orderId;
    // 商品编码
    @Field(expression = "TB_123 = taoBao_123, JD_123 = jingDong123")
    private String productCode;
    // 商品金额
    private BigDecimal amount;
}
```
