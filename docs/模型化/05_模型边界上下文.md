### 边界上下文定义

```java
@Configuration
public class MyConfiguration {
    @Bean
    public BoundedContext orderBoundedContext() {
        BoundedContext boundedContext = new BoundedContext();
        boundedContext.put("channelName", "taoBao");
        return boundedContext;
    }
}
```

### 边界上下文仓储指定

```java
@Repository(
        dataSource = OrderMapper.class,
        boundedContext = "orderBoundedContext",
        queries = OrderQuery.class
)
public class OrderRepository extends MybatisPlusRepository<Order, Integer> {
}
```

### 实体属性引入

```java
/**
 * 订单
 */
@Data
@Entity
public class Order {

    @Property("channelName")
    private String channelName;

    // 主键
    private Integer id;
    // 订单类型
    private String type;
    // 订单详情
    @Entity
    @Binding(field = "orderId", bind = "id")
    private OrderDetail orderDetail;
    // 下单时间
    private Date createTime;

    /**
     * 获取商品编码
     */
    public String getProductCode() {
        return orderDetail.getProductCode();
    }
}
```
