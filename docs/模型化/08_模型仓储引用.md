### 仓储引用

指向实体（Entity）对应仓储（Repository）的引用，称为仓储引用。

作用是方便开发者，在实体方法内部，调用仓储接口。

```java
@Data
@Entity
public class ${Entity} {
    // 静态不可变（推荐）
    public static final Ref<${Entity}> ref = new RefImpl<>();
    // 静态可变
    public static Ref<${Entity}> ref;
}
```

- 仓储引用是静态的，实体所有实例共用。
- 在启动时，自动注入。
- 仓储引用功能 >= 仓储功能。

### 静态引用

```java
${Entity}.ref.selectByPrimaryKey(Options.ROOT, id);
```

- 使用仓储引用，替代依赖注入。
