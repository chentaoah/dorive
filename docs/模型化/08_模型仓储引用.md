### 仓储引用定义

指向实体（Entity）对应仓储（Repository）的引用，称为仓储引用。

作用是方便开发者，在实体方法内部，调用仓储接口。

```java
/**
 * 订单
 */
@Data
@Entity
public class Order {
    // 仓储引用
    public static Ref<Order> ref;

    // 主键
    private Integer id;
    // 订单类型
    private String type;
    // 订单详情
    @Entity
    @Binding(field = "orderId", bind = "id")
    private OrderDetail orderDetail;
    // 下单时间
    private Date createTime;

    /**
     * 获取商品编码
     */
    public String getProductCode() {
        return orderDetail.getProductCode();
    }

    /**
     * 保存
     */
    public void save() {
        ref.insert(Options.ALL, this);
    }
}
```

- 仓储引用是静态的，实体所有实例共用。
- 在启动时，自动注入。
- 仓储引用功能 >= 仓储功能。

### 外部使用

```java
 * 订单
 */

    }

```

- 使用仓储引用，替代依赖注入。
