### 值对象定义

```java
/**
 * 支付信息
 */
@Data
public class Payment {
    // 支付方式
    private String method;
    // 支付状态
    private Integer status;
}
```

```java
/**
 * 订单
 */
@Data
@Entity
public class Order {
    // 主键
    private Integer id;
    // 订单类型
    private String type;
    // 订单详情
    @Entity
    @Binding(field = "orderId", bind = "id")
    private OrderDetail orderDetail;
    // 下单时间
    private Date createTime;

    // 支付信息
    @ValueObj
    private Payment payment;

    /**
     * 获取商品编码
     */
    public String getProductCode() {
        return orderDetail.getProductCode();
    }
}
```

### 存储方式

- 数据库存在payment字段时，以JSON格式存储。
- 数据库不存在payment字段时，Order表需包含method、status字段。
